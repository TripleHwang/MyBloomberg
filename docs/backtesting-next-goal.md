# 중장기 선정 기준 백테스트와 성과 검증

상태: 다음 개발 목표 · 2026년 10월 18일 등록

`balanced-1.1.0`의 매수·축소·관찰 기준을 당시 공개된 자료로 재현하고, 한국·미국 지수 대비 수익률과 최대 낙폭을 화면에서 비교한다. 좋은 결과가 나오도록 기준을 바꾸는 대신, 현재 기준의 효과와 한계를 측정한다. 현재 제품에는 이 백테스트와 성과 화면이 구현되지 않았으며, 기존 점수는 투자 성과가 검증된 모형으로 표시하지 않는다.

## 검증 범위

사용자가 정한 필수 범위는 다음과 같다.

- 판단 당시 알 수 있었던 데이터만 사용한다.
- 한국·미국 시장을 각각 검증하고, 해당 시장 지수와 수익률·최대 낙폭을 비교한다.
- 같은 자료·모형·실행 설정이면 같은 거래와 성과를 재현한다.
- 결과, 비교 조건, 데이터 누락과 판단 근거를 제품 화면에서 확인한다.

현재 평가 기준은 [선정 기준 문서](scoring-methodology.md)에 고정되어 있다. 일반 기업, 금융업, ETF의 모델과 순위를 섞지 않는다. 금융업은 규제자본 등 핵심 자료 미확보에 따른 관찰 제한을 유지한다. 첫 검증은 한국·미국 일반 기업 포트폴리오를 각각 대상으로 하며, ETF는 별도 실험으로 분리한다. 오버뷰의 국가별 대표 후보 표시 자리는 포트폴리오 배분 규칙으로 사용하지 않는다.

## 당시 데이터만 사용하는 원칙

### 공시와 정정 이력

재무 값마다 회계기간 종료일, 최초 공개 시각, 해당 수치가 실린 공시 식별자, 정정 공개 시각, 통화·단위·연결 범위, 원문 출처와 해시를 저장한다. 자료를 이번에 내려받은 시각은 공개 시각과 별도로 기록한다.

각 판단 시각에는 그때까지 공개된 버전만 선택한다. 정정 공시나 이후 보고서가 과거 수치를 다시 제시해도 정정 이전 판단을 덮어쓰지 않는다. 다년 추세의 각 연도와 동종 비교 대상에도 같은 조건을 적용한다. 최소 3개 연간 자료가 당시 이미 공개되어 있어야 성장 점수를 계산할 수 있다.

미국 자료는 [SEC의 제출 이력과 XBRL API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)를 조사하고 공시별 원문·접수 정보와 연결한다. SEC의 집계 API는 여러 제출본을 모으므로 최신 집계 값이나 마지막 제출 값을 반환하는 Frames를 과거에 알려진 값으로 간주하지 않는다.

한국 자료는 [OpenDART 공시검색](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001)의 접수번호·접수일과 원문·정정 이력을 연결한다. 접수일만 있고 공개 시각을 확인하지 못하면 해당 한국 날짜가 끝나기 전에는 사용하지 않는 보수적 가용 시각을 부여하고 그 정책을 표시한다. 최종 보고서만 조회해 과거 최초 제출본을 잃지 않는다. OpenDART는 인증키가 필요하며, 발급·데이터 이용 방식은 착수 단계에서 확인한다.

현재 Yahoo 연간 재무, 현재 업종·시총·주식 수를 과거 날짜에 복사하는 방식은 허용하지 않는다. 현재 4개 연간 자료만으로 장기간의 당시 정보 기반 검증이 가능하다고 판단하지 않는다. 최초 제출본이나 공개 시각을 복원할 수 없는 항목은 제외 사유를 남기며 추정한 공개일로 대체하지 않는다.

### 시세와 비교 기업

- 역사적 가격·당시 발행주식 수·통화·주식 단위를 일치시켜 당시 시가총액과 연간 P/E·P/B를 계산한다. 현재 시총, 현재 예상 실적, 현재 ADR 비율을 과거에 적용하지 않는다.
- 분할·병합·배당·합병·상장폐지·티커 변경 이력을 보존한다. 배당 조정 가격과 배당 현금을 함께 반영해 이중 계산하지 않는다. 미래 기업행사로 조정된 가격을 과거 매매 신호나 원시 시가총액 계산에 그대로 넣지 않는다.
- 과거 상장 목록, 당시 편입·제외와 업종 이력을 사용해 생존자 편향을 막는다. 현재 52개 기업만 되돌린 결과는 현재 목록의 탐색 실험으로 표시하고 시장 전체 검증으로 승격하지 않는다.
- 동종 비교는 판단 당시 알려진 동일 세부 업종, 유효 재무와 결산일 정합성으로 구성한다. 나중에 생긴 비교 기업이나 미래 업종 분류를 사용하지 않는다.
- 자료가 없는 종목·날짜와 보유 중 거래정지를 구분한다. 보유 종목의 가격이 없다고 포트폴리오에서 삭제하거나 남은 비중을 재조정하지 않는다. 상장폐지 대금·회수액을 검증하지 못한 경우 완전한 성과로 확정하지 않고 영향 범위와 보류 상태를 표시한다.

### 뉴스와 시간대

뉴스는 당시의 제목·요약 버전, 발행 시각과 공개 또는 발견 시각을 입증하는 보관 자료가 필요하다. 나중에 수정된 기사나 현재 RSS를 과거 기사로 소급하지 않는다. 판단 시각 이전에 확인 가능한 최근 24시간 기사에만 고정 규칙을 적용한다.

과거 뉴스 보관 범위가 부족하면 재무 기준만 검증한 실험과 뉴스까지 포함한 실험을 분리한다. 뉴스 포함·제외 비교는 같은 기간·종목·비용에서 수행한다. 뉴스가 없는 기간에 0점을 넣고 전체 모델을 검증했다고 표시하지 않는다. Codex의 해설은 과거 후보·매매·성과 계산에 관여하지 않는다.

모든 시간은 UTC로 보관하고 한국·미국 거래소의 실제 공휴일·서머타임·정규장 달력으로 판단과 체결을 분리한다. 미국 종가나 뉴스가 한국 장에서 아직 알려지지 않았다면 한국 판단에 넣지 않는다.

## 데이터 확보를 먼저 검증하는 단계

본 실행 전 한국·미국의 정상 공시, 정정 공시, 적자 전환, 기업행사와 상장폐지 사례를 포함한 작은 표본으로 과거 입력을 재구성한다. 아래 항목별 확보 기간, 원문 보존 여부, 공개 시각 정밀도, 누락률, 사용·재배포 조건, 비용을 데이터 점검표에 남긴다.

| 자료 | 조사할 출처와 확인할 조건 |
| --- | --- |
| 미국 재무 | SEC 공시별 원문·접수 이력·XBRL. 집계 값의 제출본 연결과 태그 정합성 |
| 한국 재무 | DART 원문·접수번호·정정 이력. 인증키와 당시 제출본 복원 가능성 |
| 상장 목록과 업종 | 거래소·공식 지수 편입 이력 또는 이용 가능한 시점별 데이터 공급자. 퇴출 기업 포함 여부 |
| 가격과 기업행사 | 당시 시가·종가·배당·분할·상장폐지 처리, 조정 방식과 조회 가능 기간 |
| 지수 | 코스피 TR·S&P 500 TR의 동일 수익률 기준 일별 이력과 이용 조건 |
| 환율 | 각 판단·평가 시각에 알려진 역사적 환율, 기준 시각과 결측 처리 |
| 뉴스 | 당시 제목·요약·시각·버전이 검증되는 보관 자료와 해당 기간의 수집 범위 |

현재 무료 공급자가 모든 자료를 제공한다고 가정하지 않는다. 기간 단축, 대체 공급자, 유료 자료가 필요하면 범위와 비용을 사용자에게 확인한 후 선택한다. 지수 대신 ETF를 사용할 경우 추적 비용과 상품 수익률임을 명시하고 지수 이력으로 표기하지 않는다.

## 착수 전에 확정할 실험 설정

다음은 비교 가능성을 위한 제안 기본값이다. 사용자가 확정한 실행 조건으로 취급하지 않으며, 데이터 점검 결과와 함께 착수 전에 확인한다.

| 항목 | 제안 |
| --- | --- |
| 벤치마크 | 한국 코스피 TR, 미국 S&P 500 TR. 배당 재투자 기준을 전략과 일치시킴 |
| 기간 | 2016년부터 2025년까지를 우선 조사. 그 이전 연간 자료를 준비 구간으로 확보하고 실제 가능 기간을 확정 |
| 판단 주기 | 각 시장 월말 정규장 종료 후, 사전에 정한 자료 반영 지연을 포함한 동일한 마감 시각 |
| 체결 | 판단이 끝난 뒤 도래하는 해당 시장의 다음 거래일 시가. 당일 종가를 보고 그 종가에 체결하지 않음 |
| 매수 포트폴리오 | 국가별 적격 매수 후보 중 점수 상위 최대 10개, 각 10% 목표 비중. 부족한 자리는 현금으로 유지 |
| 교체 | 월별 새 목표 목록으로 조정. 목록에서 빠지면 다음 체결일에 축소하며, 관찰 전환 후에도 계속 보유하는 정책은 별도 실험 |
| 매도 후보 검증 | 공매도 없이 보유 시 축소 관점. 매도 분류 이후 6·12개월 상대성과를 별도 집계하고 월별 교체 매도와 구분 |
| 거래 조건 | 무차입·공매도 없음. 첫 계산은 소수 주식 허용 연구 모형임을 명시하고 실제 주문 재현과 구분 |
| 비용 | 제안 기준은 매수·매도 각각 수수료 10bp와 슬리피지 10bp. 실제 수수료라고 주장하지 않고 0·20·50bp 민감도도 병기 |
| 세금과 현금 | 거래 관련 세금은 시장·시기별 표를 검증해 반영. 현금 기본 이자는 0으로 고정하고 개인 양도소득세·배당 원천징수 가정을 별도 명시 |
| 환율 | 국가별 현지 통화 비교와 함께 한국 투자자용 원화 환산 비교 제공. 전략·지수에 동일 환율·평가 시각 적용 |

세금 이력을 확보하지 못하면 비용 차감 후·세금 차감 전 결과로 표시한다. 이를 모든 비용이 반영된 실수익률로 부르지 않는다. 매매 가능성·거래량·시장 충격을 검증하지 못한 실험은 투자 가능 규모를 주장하지 않는다.

월별 교체 정책 자체의 영향을 구분하기 위해 같은 당시 종목 범위의 단순 동일 비중 포트폴리오도 보조 비교군으로 둔다. 같은 모델 내 점수와 심볼 동점 순서를 고정하고 금융업·ETF 점수를 일반 기업 순위에 섞지 않는다.

## 성과 계산과 유효성 판단

성과는 현금·배당·보유 평가액·거래비용을 포함한 일별 자산 가치로 계산한다. 현지 통화 전략은 해당 시장의 동일 통화 지수와, 원화 환산 전략은 같은 방식으로 원화 환산한 지수와 비교한다. 같은 날짜 범위·초기 기준값·배당 기준을 사용하고 가격 수익률과 총수익률을 한 표에서 동일 기준처럼 섞지 않는다. 총수익 지수를 확보하지 못하면 그 비교를 보류하거나 양쪽 모두 가격 수익률인 별도 실험으로 분리한다.

| 지표 | 정의와 표시 |
| --- | --- |
| 누적 수익률 | 마지막 자산 가치 / 최초 자산 가치 − 1. 최초 매수 비용도 반영 |
| 연환산 수익률 CAGR | 자산 가치 배율을 실제 경과 연수로 연환산 |
| 지수 대비 초과수익 | 같은 기간 전략 수익률 − 지수 수익률, %p |
| 일별 낙폭 | 1 − 당일 자산 가치 / 그날까지의 최고 자산 가치 |
| 최대 낙폭 MDD | 일별 낙폭의 최댓값을 양의 손실률로 표시. 전략 MDD − 지수 MDD가 양수면 전략이 더 큰 손실 |
| 회복과 운용 부담 | 최대 낙폭의 고점·저점·회복일, 미회복 여부, 회전율·비용·현금 비중 |
| 표본과 일관성 | 연도별 성과, 6·12개월 보유 구간별 상대성과, 평가·제외 종목 수와 날짜별 자료 커버리지 |

누적 수익률 한 번의 우위만으로 유효성을 확정하지 않는다. 한국·미국을 각각 보고 비용 반영 전후, 하락 구간, 연도별·이동 구간의 일관성과 집중도를 확인한다. 겹치는 보유 구간의 상관을 고려한 신뢰구간을 제공한다면 블록 길이·난수 시드·추출 설정도 저장한다. 결과는 지수 우위, 위험 증가, 불확실한 표본을 함께 설명하며 성과가 나빠도 결과를 그대로 보존한다.

실험 전에 모형 버전과 설정을 잠근다. 과거 데이터가 점수 설계나 설정 선택에 사용되었는지 기록하고 이미 확인한 기간을 독립된 미래 검증으로 부르지 않는다. 설정 탐색을 추가하면 탐색 구간과 평가 구간을 시간순으로 분리하고 모든 시도를 보관한다. 실제 미관측 구간 검증은 사양 확정 후 첫 거래일부터의 모의 운용으로 이어간다.

## 성과 화면

기존 데스크에 검증 화면을 추가하고 오버뷰에는 최신 검증 상태와 결과로 이동하는 짧은 링크를 둔다. 반복되는 소개 문구 없이 비교 결과부터 보여준다.

- 상단에 시장·기간·현지 통화/원화·재무 전용/뉴스 포함 실험을 선택하고 모델 버전·기준 시각·자료 적격 상태를 표시한다.
- 전략과 지수의 누적·연환산 수익률, 초과수익, 최대 낙폭을 같은 표에서 보여준다. 비용·현금·배당·세금 가정은 바로 확인할 수 있게 한다.
- 같은 초기값으로 시작하는 자산 가치 곡선과 별도 낙폭 곡선을 제공한다. 특정 날짜에서 전략·지수·현금 비중을 함께 읽는다.
- 연도별·보유 구간별 결과와 자료 누락·제외 현황을 펼쳐볼 수 있게 한다. 불리한 기간도 기본 범위에 포함한다.
- 리밸런싱 날짜를 선택하면 당시 후보·요소별 점수·동종 비교·기사 기여·공시 원문·공개 시각·체결 내역을 추적한다.
- 자료 부족, 계산 중, 실패, 탐색용 결과, 당시 정보 검증 완료를 구분한다. 미확보 값을 0% 성과나 검증 완료로 표시하지 않는다.
- 결과·거래·일별 자산 가치는 CSV, 설정·입력 해시·자료 목록은 JSON으로 내려받고 아카이브에서 같은 실행을 재현한다. 모바일 표는 영역 안에서 스크롤한다.

## 구현 순서와 완료 기준

1. **자료 점검:** 두 시장의 과거 공시·정정·상장 목록·기업행사·지수·뉴스 확보 가능성을 기록하고 실행 조건을 사용자와 확정한다. 필수 자료가 부족하면 검증 가능한 범위를 명시한다.
2. **당시 입력 재생:** 공개 시각으로 재무·업종·시총·환율·뉴스를 조회하고 `balanced-1.1.0`과 연결한다. 기존 실시간 스냅샷의 점수·버전을 변경하지 않는다. 과거 데이터 계약이 다르면 연결 버전을 추가한다.
3. **거래와 비교 계산:** 거래소 달력, 다음 거래일 체결, 비용·배당·상장폐지·현금 장부, 지수와 성과 지표를 구현한다. 실행 ID·코드 커밋·모형 버전·설정·데이터 manifest·해시와 결과를 불변 저장한다.
4. **검증 화면:** 비교 표·자산 가치·낙폭·리밸런싱 근거·누락 상태·내려받기와 아카이브를 연결한다.
5. **독립 검산:** 수기로 확인한 작은 장부와 자동 계산을 대조하고 실제 자료로 두 시장을 실행한다. 결과와 한계를 남기고 후속 모의 운용을 시작한다.

완료 검증에는 다음 조건이 모두 필요하다.

- 미래 공시·뉴스, 이후 정정본, 미래 비교 기업을 주입해도 그 이전 날짜의 후보·거래가 변하지 않는다. 변경 시점부터만 영향을 받는다.
- 공개 시각 전후, 미국 서머타임·한국/미국 휴장일, 다음 시가 체결을 경계 테스트로 확인한다.
- 분할·배당·거래정지·상장폐지·보유 가격 누락을 포함한 장부에서 이중 배당과 자산 삭제가 없다.
- 수기로 계산한 수익률·비용·최대 낙폭과 일치하며, 입력 배열 순서를 바꾸거나 재실행해도 동일한 결과가 나온다.
- 한국·미국 각각의 전략·지수 성과와 비교 기준이 화면·내려받기에서 일치한다. 실제 가능한 기간과 제외 범위가 보인다.
- 뉴스 이력이 부족하면 재무 전용 결과가 명확히 표시되고 전체 뉴스 포함 모형의 검증으로 오인되지 않는다.
- 지수 초과성과의 성공 여부와 개발 완료를 분리한다. 저조한 수익률이나 더 큰 낙폭이 나와도 숨기거나 기존 배점을 조정해 덮어쓰지 않는다.

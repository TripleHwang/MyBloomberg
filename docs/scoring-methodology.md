# 균형형 중장기 평가 기준

현재 모형: `balanced-1.1.0`. 투자 기간은 수개월 이상입니다. 점수는 이 프로젝트가 정한 비교 규칙이며 상승 확률·미래 수익률이 아닙니다. 가중치·구간·문턱을 백테스트로 최적화하지 않았습니다.

다음 개발 목표는 [당시 공개된 자료를 사용하는 백테스트와 한국·미국 지수 대비 성과 화면](backtesting-next-goal.md)입니다. 현재 자료를 과거 시점에 소급하지 않고 공시·정정 이력과 당시 종목 구성을 먼저 확보합니다. 아직 검증 결과는 없습니다.

## 재현성과 역할

- 수집본에 점수·분류·대표 후보·모형 버전·입력 SHA-256 지문을 함께 저장합니다.
- 점수 계산에는 모델 호출·현재 실행 시각·난수·외부 재조회가 없습니다. 수집 기준 시각과 저장된 데이터만 사용합니다.
- 입력 정렬과 동점 순서를 고정합니다. 같은 자료와 버전이면 배열 순서를 바꾸어도 결과가 같습니다.
- Codex는 시장·한국 투자자·환율 맥락을 설명합니다. 후보·점수·분류·후보별 확인 조건은 고정 계산 결과를 결합하므로 AI가 변경할 수 없습니다. 시장 해설 문장은 재생성 시 달라질 수 있습니다.
- 과거 수집본은 당시 평가 버전을 유지합니다. 원자료가 변하거나 모형 버전이 바뀌면 결과도 달라질 수 있습니다.

## 연간 재무와 데이터 요건

Yahoo 연간 재무 시계열의 12개월 결산 자료를 최대5개 사용합니다. 현재 무료 자료는 주로4개 회계연도를 제공합니다. 빈 연도, 미래 결산, 분기·TTM 자료는 연간 표에 섞지 않습니다. FCF가 없고 영업현금흐름·설비투자가 모두 있으면 `FCF = 영업현금흐름 − |설비투자|`로 계산하고 그 사실을 표시합니다.

매매 분류에는 정상 시세·현재 재무 요약, 최소3개 연속 연간 결산(결산 간격300~430일), 알려진 보고 통화, 최신 연간 결산550일 이내, 최근 연간 매출·이익, 본인 외 비교2개 이상, 지표 커버리지80% 이상, 동종 비교 요소의 절반 이상 자료를 요구합니다. 자료 요건을 충족하지 않으면 관찰이며 제한 이유를 표시합니다.

누락 지표는 0점으로 만들지 않습니다. 커버리지는 확보한 지표의 배점/전체 배점입니다. 80% 이상일 때 확보 배점만으로 100점 환산한 부분 자료 점수를 제공하며, 80% 미만은 총점 산출을 보류합니다. 자료·비교 요건과 매수·축소의 추가 조건은 별개입니다.

## 일반 기업: 기본100점

아래 구간 사이는 선형이며 범위 밖은 해당 최저·최고 점수로 제한합니다.

| 부문 | 지표 | 배점과 계산 |
|---|---|---|
| 다년 성장20 | 매출 CAGR | -10% 이하0점, 20% 이상12점 |
| | 순이익 CAGR | -10% 이하0점, 20% 이상8점. 모든 평가 연도 이익이 양수일 때만 계산 |
| 수익성20 | 연간 순이익률 중앙값 | 0~20% → 0~8점 |
| | 평균자본 기준 ROE 중앙값 | 순이익/기초·기말 평균자본, 0~25% → 0~6점 |
| | 첫해 대비 최근 순이익률 변화 | -5~+5%p → 0~6점 |
| 현금20 | 양의 FCF 연도 비율 | 모든 연도 FCF가 확인될 때 비율×10점 |
| | FCF/매출 중앙값 | 0~15% → 0~10점 |
| 안정성20 | 최근 연간 총이자부채/자기자본 | 0.3배 이하10점, 2배 이상0점. 확인된 자본잠식0점 |
| | 처음 대비 최근 부채/자본 변화 | 0.3배 하락5점, 0.3배 상승0점 |
| | 양의 자기자본 연도 비율 | 모든 연도 자본이 확인될 때 비율×5점 |
| 동종 비교20 | 연간 이익 기준 P/E | 낮을수록 유리한 동종 백분위×10점 |
| | 연간 자본 기준 P/B | 낮을수록 유리한 동종 백분위×5점 |
| | 최근 연간 FCF/매출 | 높을수록 유리한 동종 백분위×5점 |

CAGR은 최초·최종 회계연도 사이 실제 날짜 간격을 연수로 환산합니다. 적자나0이익을 포함한 이익 CAGR은 산출하지 않으며 흑자 전환을 임의의 성장률로 바꾸지 않습니다.

## 동종 비교와 통화

- 기업은 Yahoo의 동일 세부 `industryKey`와 최근 연간 결산일 차이200일 이내 조건을 사용합니다. 넓은 섹터가 같다는 이유만으로 비교하지 않습니다.
- 비교 표의 중앙값과 백분위에서 대상 자신을 제외합니다. 지표마다 최소2개 유효 비교가 있어야 합니다. 동점은 중간 순위입니다.
- P/E·P/B는 **현재 시가총액/최근 연간 순이익·자기자본**으로 전 기업에 같은 기준을 적용합니다. TTM PER·예상 PER과 구분합니다. 확인된 적자·자본잠식은 낮은 배수를 저평가로 해석하지 않습니다.
- 시가총액 통화와 재무 통화가 다르면 같은 수집본의 정상 환율을 사용합니다. `보고통화 시총 = 거래통화 시총 ÷ USD당 거래통화 × USD당 보고통화`. 환율이 없거나 지연되면 배수 산출을 보류합니다. 환산식은 상세에 남깁니다.
- 표의 비교 기업·결산일·실제 지표·중앙값·백분위를 공개합니다. 수집 목록은 전체 업계를 대표하지 않으며 국가별 회계기준·시장 프리미엄 차이는 남아 있습니다.

## 매수·축소·관찰

일반 기업의 매수 검토는 자료 요건에 더해 총점70 이상, 기본65 이상, 최근 연간 순이익·FCF·자기자본 양수, 최근3년 중2년 이상 흑자, 연간 P/E·P/B 가격 비교 최소3점을 요구합니다. 총점이 높아도 추가 조건을 충족하지 않으면 관찰이며 그 이유를 표시합니다.

축소 검토는 총점40 이하·기본45 이하와 함께 적자·음의 FCF·자본잠식·음의 매출 CAGR·부채/자본2배 초과 중 하나 이상을 요구합니다. 보유 시 재검토 관점이며 보유하지 않은 종목의 공매도 제안이 아닙니다. 나머지는 관찰입니다. 매수·축소 개수를 채우지 않습니다.

오버뷰는 분류별 최대4개의 대표 후보를 보여줍니다. 매수·축소는 미국 기업2·한국 기업1·ETF1 표시 자리를 우선하며 빈 자리는 같은 분류로 채웁니다. 관찰은 관심 종목을 먼저 보여줍니다. 이는 자산 배분 권고가 아닙니다. 전체 분류·점수는 종목·ETF의 전체 평가에서 확인합니다.

## 금융업과 ETF

은행·보험·일부 금융·리츠는 일반 기업의 부채·FCF 점수로 평가하지 않습니다. 성장25·수익성25·장부자본/흑자25·동종 배수25점의 참고 평가를 제공하지만 규제자본·지급여력·FFO 등 핵심 지표가 없어 자동 매수·축소는 보류합니다. 장부 자기자본/자산은 CET1이 아닙니다.

ETF는 비용30·가격 위험30·관측 추세20·동일 유형 비교20점입니다. 연간 비용0.03% 이하30점/0.30% 이상0점, 일별 연율 변동성5~45%에15~0점, 최대낙폭5~50%에15~0점, 가격 변화-20~+20%에0~20점, 동일 유형의 비용·낙폭 백분위 각10점입니다. 위험·추세 계산에는 실제 일별 가격200개 이상이 필요합니다. 매수는 변동성35%·낙폭40% 이내를 추가로 요구하고, 축소는 음의 가격 변화 또는30% 초과 낙폭을 함께 요구합니다.

ETF 기업 결산·기업 CAGR은 적용하지 않습니다. 같은 유형도 지수·상장 통화·환헤지가 다를 수 있습니다. 배당·환율 포함 총수익률이나 추적오차를 평가하는 모형은 아닙니다. 서로 다른 모델의 점수를 섞어 순위를 매기지 않습니다.

## 뉴스 기여도

최근24시간의 공개 제목·요약에 고정 회사명 별칭 또는 업종 표현을 연결하고, 아래 사건 표현을 규칙으로 판별합니다. 기사 전문을 확인하거나 미래 이익을 추정하지 않습니다.

| 기업 직접 사건 | 원점수 |
|---|---:|
| 연간 실적 전망 상향 / 하향 | +2 / -2 |
| 실적 예상 상회 / 하회 | +1 / -1 |
| 배당 확대 / 축소 | +0.5 / -0.5 |
| 신용등급 상향 | +1 |
| 채무불이행·파산 신청 관련 보도 | -3 |
| 회계 부정·재작성 관련 보도 | -2 |
| 업종의 견조한 수요·성장 / 수요 둔화 | +0.25 / -0.25 |

ETF 직접 사건은 보수 인하+1·인상-1·청산 발표-2를 사용합니다. 기업 이익 사건을 ETF 이익으로 해석하지 않습니다.

- 직접 기업 연결과 업종 간접 연결을 구분합니다. 출처 적용 목록 밖의 기사, 정의된 사건이 없는 가격 상승 보도, 조건부·부인·상충 표현은0점입니다. 키워드 휴리스틱의 오류 가능성이 있으며 사실 확인이나 검증된 예측 확률이 아닙니다.
- 같은 사건 표현의 중복 기사는 추가 가산하지 않습니다. 전체 순조정은±5점, 최종 총점은0~100으로 제한합니다. 상한 적용 시 기사 기여를 비례 축소하고0.01점 단위로 합계를 맞춥니다.
- 기사마다 제목·링크·출처·시각·연결 단어·규칙·원점수·실제 반영점수를 보존합니다. 뉴스 전후 분류와 분류 변경 여부도 표시합니다.
- 0점은 위험 부재가 아닙니다. 기사 미일치·분류 보류·공급자 실패를 구분합니다. 기본 점수 자체가 없으면 기사 연결만 표시하고 점수 가감을 보류합니다.

## 해석상의 한계와 참고

연간 자료는 현재 공급자 요약·재작성 이력이며 실제 공시 발표일을 확보하지 않았습니다. 과거 시점에서 이용 가능했던 정보만으로 한 백테스트를 보장하지 않습니다. 기업 공시 전문·동종 업계 전체·개인 보유 비중을 검토하지 않았습니다. 영업 구조가 다른 기업을 동일 업종으로 분류하는 공급자 한계도 남아 있습니다.

연간 자료 수집은 [yahoo-finance2의 재무 시계열 모듈](https://github.com/gadicc/yahoo-finance2/blob/dev/src/modules/fundamentalsTimeSeries.ts)을 사용합니다. 수익성·이익 지속성·레버리지를 구분하는 관점은 [MSCI의 품질 지표 설명](https://www.msci.com/indexes/group/quality-indexes)에서도 확인할 수 있습니다. 이 프로젝트의 수식·배점은 자체 설계이며 해당 지수의 구현이나 성과를 재현하는 것이 아닙니다.
